# E-commerce Sales & Project Analytics 
An end-to-end Data Analytics project built using **SQL (PostgreSQL), Power BI, and Excel** to analyze sales performance, customer behavior, and profitability.
## Project Overview 
This project demonstrates the complete data analytics workflow-from cleaning raw data and writing SQL queries to building interactive Power BI dashboards and generating business insights.
**Tools Used** 
- PostgreSQL
- Power BI
- Microsoft Excel
- SQL
- DAX
